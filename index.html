與 Game Generator 的流程

  1. 在 Generator 選年級、課題與玩法，複製提示詞並生成 HTML 遊戲。
  2. 把遊戲上傳到 GitHub Pages 或學校網站，取得可開啟的網址。
  3. 回到本平台按「分享遊戲」，填班別學號與網址，複製共享連結給同學。
資源庫會載入內建遊戲目錄，並合併本機與共享連結中的同學作品。資料暫存於瀏覽器；複製共享連結即可帶到其他裝置。
